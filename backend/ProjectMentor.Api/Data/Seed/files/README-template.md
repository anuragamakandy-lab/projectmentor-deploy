## Getting started

### Prerequisites
- e.g. .NET 8 SDK, Node.js 20+, PostgreSQL 16+

### Installation
```bash
git clone https://github.com/<user>/<repo>.git
cd <repo>
# backend
cd backend && dotnet restore
# frontend
cd ../web && npm install
```

### Configuration
Copy `appsettings.Local.example.json` to `appsettings.Local.json` and fill in your own values.
**Never commit real passwords or API keys.**

### Run
```bash
# terminal 1
cd backend && dotnet run
# terminal 2
cd web && npm run dev
```
Open http://localhost:5173
